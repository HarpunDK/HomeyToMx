Logitech MX Keypad

This Homey Pro app receives button events from the Logitech MX Creative Keypad Actions plugin and exposes nine Flow triggers named "Trigger 1" through "Trigger 9". Each trigger corresponds to one keypad key, so flows do not need a button-number condition.

Setup

1. Install and start this app on Homey Pro.
2. Open the app settings and copy the integration key.
3. Configure the Logi Homey Actions plugin using the endpoint and key. See the plugin README for the config file format and location.

The API is available only on Homey Pro. Its public local route requires the generated integration key on every request. Keep the key private and use the endpoint only on your trusted local network.
